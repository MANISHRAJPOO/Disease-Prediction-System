# Disease Prediction System

A Machine Learning based Disease Prediction System developed as a college major project.

## Project Overview

This project uses Machine Learning techniques to predict the possibility of:

* Diabetes
* Heart Disease

The system accepts health-related input parameters and produces a prediction using trained Machine Learning models.

## Machine Learning Models

The following algorithms are used:

1. Logistic Regression
2. Random Forest
3. Support Vector Machine (SVM)

## Project Workflow

1. Define Problem
2. Collect Data
3. Data Preprocessing
4. Feature Selection and Normalization
5. Train Machine Learning Models
6. Evaluate Model Performance
7. Cross-Validation
8. Develop Prediction UI
9. Ethics, Limitations and Future Improvements

## Evaluation Metrics

The models are evaluated using:

* Accuracy
* Precision
* Recall
* F1 Score
* Confusion Matrix
* 5-Fold Cross-Validation

## Disclaimer

This project is developed for educational and research purposes only.

The predictions generated by this system should not be considered medical diagnoses and should not be used for medical treatment or decision-making.
